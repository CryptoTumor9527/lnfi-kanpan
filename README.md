# Lnfi 看盘（纯网页版）

RGB / Taproot Assets 在 Lnfi P2P 市场上的个人看盘页面，所有时间按北京时间（UTC+8）显示。

纯静态网页：没有后端，也不需要构建。数据由你的浏览器直接请求 Lnfi 公开接口 `https://api.lnfi.network`；BTC 价格取自 mempool.space。

## 怎么打开

- **GitHub Pages**：把本仓库推到 GitHub，在仓库的 Settings → Pages 里选 “Deploy from a branch”，分支选 `main`、目录选 `/ (root)`。保存后打开 `https://<用户名>.github.io/<仓库名>/` 即可。
- **本地**：在本目录运行 `python3 -m http.server 8800`，然后打开 http://localhost:8800/ 。直接双击 index.html 打开不保证能用，因为 IndexedDB 和跨域请求在 file:// 下可能受限。

## 加载方式

- 第一次打开时只拉最近 60 天的成交，PPRGB 优先。页面顶部会显示 “加载中 x/7 · 市场 第 N 页”，已加载的数据会先显示出来。整体大约 1–2 分钟。
- 数据缓存在本机浏览器的 IndexedDB 里。之后再打开只补拉新成交，十几秒就能好。
- 换设备、换浏览器或清空浏览器数据后，需要重新首次加载。
- 请求逐个发出、每次间隔约 250ms，出错时自动退避，避免给 Lnfi 接口造成压力。

## 刷新频率（只在页面处于前台时进行）

| 内容 | 频率 |
|---|---|
| 成交、市场列表 | 60 秒 |
| 挂单簿 | 3 分钟 |
| 持有人 | 15 分钟 |
| BTC 价格 | 5 分钟 |

## 指标口径

- **价格**：实际成交价（sats/枚）。
- **成交**：一笔 P2P 成交在 Lnfi 历史里是挂单、吃单两条记录，这里按吃单只算一次。吃单方向就是买入/卖出方向。
- **成交额**：单位为 sats，可切换为 USD。
- **涨跌幅**：最新价与 24h/7d/30d 前价格的比较。
- **较上期**：与上一个同长度窗口的比较。数据覆盖不到上一个窗口时不显示。
- **钱包**：窗口内参与成交的不同 Nostr 公钥。
- **隐含 FDV**：总供应量 × 最新成交价。
- **持有人**：来自 Lnfi 资产账本。“未在市场成交过”是指该地址在最近 60 天的成交记录里没有出现。

## 限制

- 只有最近约 60 天的数据，所以日线和持有人的 “未在市场成交过” 标记都只覆盖 60 天。
- 少数成交的挂单方早于 60 天，查不到挂单方，导致 30d 钱包数会比完整历史略少（约 1%）。
- 页面在后台时停止刷新，切回前台后会自动补上。
- 完全依赖 Lnfi 公开接口；接口变动或不可用时页面无法更新。

与 Lnfi 无关联，不构成投资建议。
